# 01. Rocky Linux 설치

## 목표
VirtualBox 가상머신에 Rocky Linux 9.8을 설치하고, 이후 실습의 기반이 되는 환경을 만든다.

## 환경
- 호스트: Windows PC
- 가상화: Oracle VirtualBox
- 게스트 OS: Rocky Linux 9.8 (메모리 4GB, CPU 3개, 디스크 30GB)

## 실습 과정
1. Rocky Linux 9 ISO 다운로드
2. VirtualBox에서 VM(LinuxStudy) 생성 후 ISO 연결
3. 설치 진행 (저장소: 자동 설정, root 암호 및 일반 사용자 생성)
4. 설치 후 ISO 제거, 재부팅 후 로그인 확인
5. 네트워크 확인 (ip a, ping), sshd 실행 상태 확인

## 오류와 해결
### 1. 설치 목적지 화면의 저장소 구성 오류
- **증상**: "sda / 1.97 MiB 남음"으로 표시되고 저장소 구성 오류 발생
- **원인**: 가상 디스크에 기존 파티션이 남아 있어 빈 공간이 없다고 인식됨
- **해결**: 디스크를 선택하고 "추가 공간을 사용할 수 있게 합니다" 체크 후 완료, "모든 삭제 → 공간 회수" 진행

## 정리
- 가상 디스크는 실제 PC 데이터와 분리되어 있어 마음껏 실습할 수 있다.
