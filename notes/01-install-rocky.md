\# 01. Rocky Linux 설치



\## 목표

VirtualBox에 Rocky Linux 9.8을 설치하고 스냅샷을 만든다.



\## 실습 과정

1\. Rocky Linux 9 ISO 다운로드

2\. VirtualBox VM(LinuxStudy) 생성 후 ISO 연결

3\. 설치 진행 (저장소: 자동 설정, root 암호 및 일반 사용자 생성)

4\. ISO 제거 후 재부팅, 스냅샷 생성



\## 오류와 해결

\- \*\*증상\*\*: 설치 목적지 화면에 "sda / 1.97 MiB 남음"과 저장소 구성 오류

\- \*\*원인\*\*: 가상 디스크에 기존 파티션이 남아 있어 빈 공간이 없다고 인식됨

\- \*\*해결\*\*: 디스크를 선택하고 "추가 공간을 사용할 수 있게 합니다" 체크 후 완료 → "모든 삭제 → 공간 회수"



\## 정리

\- 스냅샷은 되돌리기 지점이라 큰 실습 전에 찍어 둔다.
